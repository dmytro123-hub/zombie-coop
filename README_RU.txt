ЗОМБИ: ЗАЩИТА БАЗЫ — ОНЛАЙН-КООПЕРАТИВ

Файлы проекта находятся в корне архива:
- index.html — игра
- server.js — сервер комнат и синхронизации
- package.json — зависимости и команда запуска

Запуск: npm start

После импорта проекта на Node.js-хостинг запусти npm start и опубликуй приложение как серверное Node.js-приложение с поддержкой WebSocket. Оба игрока должны открыть один и тот же HTTPS-адрес опубликованного приложения, а не локальный content:// файл.

Проверка сервера: добавь /health к адресу сайта. Ожидается JSON с ok:true.

Важно: публикация и постоянная работа сервера могут быть платными или иметь ограничения. Не вводи платёжные данные без согласования с родителем/опекуном.
